# 아랍어 살롱 — Bruno 아랍어 기초 학습 앱

`index.html`을 더블클릭해서 브라우저로 열면 끝. 서버·빌드·설치 불필요.

## 구성

- `index.html` — 앱 전체 (대시보드 / 단어 카드 / 복습 퀴즈 5종 / 문법 패턴 / 운전 모드 / 회화 표현)
- `data.js` — 모든 학습 데이터 (단어 115개 + 회화 표현 + 예문 + 문법 패턴)
- `pdf/` — 프린트용 큰 글씨 단어장
- `sources/` — 수업 원본 (SRT, 문법 PDF). 매주 새 자료를 여기에 넣는다.

## 매주 새 수업 자료 추가하는 법

1. 새 녹화본 SRT / Notion 정리 / 수업 PDF를 `sources/`에 복사
2. Claude Code에 요청: "sources/의 새 자료에서 새 단어·문법·예문을 추출해서 data.js에 추가해줘"
   - 새 단어 → `VOCAB` 배열 맨 아래 append (`date`에 수업 날짜)
   - 새 회화 표현 → `PHRASES`
   - 새 예문 → `EXAMPLES`
   - 새 문법 패턴 → `PATTERNS` / `HAL_ITEMS`
   - 기존 단어와 `id` 중복 체크
3. 브라우저 새로고침하면 카드·퀴즈·운전 모드에 자동 반영

## 기록 방식

- 오늘 틀린 단어 / 본 카드 수는 브라우저 localStorage에 날짜별로 저장 (오늘의 복습에 사용)
- TTS는 브라우저 내장 음성 사용 (아랍어 Majed, 한국어 유나) — 오프라인에서도 동작
